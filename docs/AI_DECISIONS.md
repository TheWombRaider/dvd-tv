# Decisions

- Standalone dvd-tv application, separate package from pipes-tv.
- Offline native animation rather than YouTube playback or a bundled recording.
- Fidelity comes from measured reference frames; document uncertainty rather than claim unsupported identity.
- Preserve the current TV screensaver selection. Install and preview only.
- OpenCode uses official Codex tools; switch manually to official Antigravity if quota is exhausted. Persist task state rather than introduce a router or custom daemon.
- Use a fixed 60 Hz discrete simulation in a 1920x1080 logical plane, uniformly fitted to the display. Preemptive lattice reflections reproduce the measured gaps at walls; contact-frame color changes precede reversed displacement by one tick.
- Preserve the 78 measured opening colors, then generate deterministic pastels. Do not loop footage or claim an unknown ten-hour random sequence is reproduced.
- Share one renderer between launcher preview and DreamService. Run callbacks only while visible and use a monotonic active clock.
- Keep the unexplained 150-second endpoint discrepancy as an excluded diagnostic. Acceptance is based on independent held-out frames and actual device captures, with explicit limits.
- Follow pipes-tv's local debug signing convention for sideload builds. Publish source and build instructions, not APKs or signing keys.
